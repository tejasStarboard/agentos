# 51 — Chore: monorepo clean + Python uv sync on install

**Status:** in-progress

## Goal

Add a reliable root **`clean`** pipeline (Turbo + leftover JS/Python caches) and wire **`uv sync`** into root **`pnpm install`** (`postinstall`) so Python SDK + `services/*` envs are ready after a normal install.

## Depends on

- None (chore / tooling). Can land anytime.

## Done when

- [x] Root `clean` runs `turbo run clean` then clears leftover artifacts (`.venv`, `__pycache__`, `.pytest_cache`, `.turbo`, `dist`, `node_modules`, etc.)
- [x] `turbo.json` defines `clean` with `cache: false` (not `persistent`)
- [x] Workspace package `clean` scripts remove the same class of local artifacts
- [x] Root `postinstall` / `python:sync` runs `uv sync` for `packages/python` (dev extras) and every `services/*/pyproject.toml`
- [x] Soft-skip with a warning when `uv` is missing (CI without uv still installs JS)
- [x] Commit `packages/python/uv.lock` when generated by sync

## Notes

- Do not delete `.git` or Cursor index data from `clean`.
- Prefer Bun scripts under `scripts/` for sync/clean (ADR 001).

## Verify

- `pnpm run clean` leaves no `node_modules` / `.venv` / `.turbo`
- `pnpm install` runs postinstall and creates Python `.venv`s when `uv` is available
- `bun run ci`
